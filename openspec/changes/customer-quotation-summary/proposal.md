# Cotización resumida para clientes

El cliente solicita un único concepto con resumen y total en la cotización. Añadir un resumen por versión comercial, conservando líneas internas, versionado y plantillas WhatsApp. Cubrir diagnóstico, recotización, Express, vista previa y recordatorios.

Migración aditiva nullable para historial. Rollback: revertir consumidores antes de retirar la columna; conservar datos del resumen para no perder documentos históricos. Sin reinicio de datos ni cambio fiscal.
